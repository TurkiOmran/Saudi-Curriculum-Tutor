# مقرر القرآن الكريم

|  الصفحة | الموضوع  |
| --- | --- |
|  ١٢ | خطة مقرر القرآن الكريم  |

## التوحيد

|  الصفحة | الموضوع  |
| --- | --- |
|  ١٥ | الوحدة الأولى: وُجُوبُ صَرْفِ الْعِبَادَةِ للهِ وَحْدَهُ لَا شَرِيكَ لَهُ  |
|  ١٦ | الدرس الأول: إِسْتِحْقَاقُ اللَّهِ لِلْعِبَادَةِ وَحْدَهُ لَا شَرِيكَ لَهُ  |
|  ١٨ | الدرس الثاني: مَكَانَةُ الْأَنِيبَاءِ ﷺ، والتحذير من الغلو فيهم  |
|  ٢١ | الدرس الثالث: مَكَانَةُ نَبِيَّنَا مُحَمَّدٍ ﷺ وَالتَّحْذِيرُ مِنَ الْغُلُوِّ فِيهِ  |
|  ٢٣ | الدرس الرابع: عَقِيدَةُ الْمُسْلِمِينَ فِي نَبِيِ اللَّهِ عِيسَى ابْنِ مَرْيَمَ ﷺ وَالتَّحْذِيرُ مِنَ الْغُلُوِّ فِيهِ  |
|  ٢٥ | الدرس الخامس: عَقِيدَةُ الْمُسْلِمِينَ فِي المَلَائِكَةِ ﷺ، والتَّحْذِيرُ مِنَ الْغُلُوِّ فِيهِ  |
|  ٢٨ | الدرس السادس: مَكَانَةُ الْأَوْلِيَاءِ وَالصَّالِحِينَ وَالتَّحْذِيرُ مِنَ الْغُلُوِّ فِيهِ  |
|  ٣١ | الوحدة الثانية: الإخلاص لله وما يضادّه  |
|  ٣٢ | الدرس السابع: شُرُوط قَبُولِ الْعِبَادَةِ  |
|  ٣٤ | الدرس الثامن: الرِّبَاءُ  |
|  ٣٧ | الدرس التاسع: إِرَادَةُ الدُّنْيَا بِعَمَلِ الْآخِرَةِ  |
|  ٣٩ | الوحدة الثالثة: عبادات وقع فيها الشرك  |
|  ٤٠ | الدرس العاشر: الِاسْتِغَانَةُ وَالِاسْتِغَادَةُ  |
|  ٤٦ | الدرس الحادي عشر: الدُّبْخَ  |
|  ٥٠ | الدرس الثاني عشر: الطَّوَافُ وَالْعُكُوف  |
