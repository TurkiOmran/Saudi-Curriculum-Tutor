# Iter_rows

ίستخدَم دالة Iter_rows عندما تردد الحصول على جميع القيم لصف أو أكثر في ورقة عمل إكسل.

![img-306.jpeg](img-306.jpeg)

إذًا لم تحدد الفهرس، فسيبدأ نطاق البحث من الخلية الأولى "A1".

نستخدَم دالة iter_rows الآن للحصول على جميع الحقائق الغذائية للحليب. عليك الحصول على جميع مواقع الخلايا لصف الحليب، وهو "3D" ثم استدعاء سمة القيمة.

## import openpyxl

```python
path = "nutrition.xlsx"
wb = openpyxl.load_workbook(path)
sheet_obj = wb['arabic']
```

أنشئ متغير صفوف يحتوي على مواقع حقائق التغذية الخاصة بالحليب

```python
rows = sheet_obj.iter_rows(min_row=3, max_row=3, min_col=3, max_col=11)
```

المتداخلة لطباعة قيمة كل خلية r of الآن استخدم حلقات od

```python
print("حقائق غذائية عن الحليب:", end="")
for row in rows:
for cell in row:
print(cell.value, end="")
```
