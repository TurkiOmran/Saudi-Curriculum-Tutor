# الوحدات الرقمية

الوحدة الرقمية الأساسية تسمى البت (Bit)، ويمكن أن تأخذ القيمة 1 أو 0، وتسمى هاتان القيمتان بالأرقام الثنائية (Binary digits)، ويمكن أن يكون لها معاني مختلفة. المعنى الأكثر شهرة هو حالتي التنشيط: تشغيل/إيقاف (On/Off).

كما هو الحال في القياسات الأخرى، تستخدم الوحدات الثنائية البادئات (prefixes):

|  وحدات تخزين المعلومات |   | البادئة  |
| --- | --- | --- |
|   | (bit) 1 بت | (b) 1 بت  |
|   | (bit) 1024 بت | (Kb) 1 كيلوبت (Kb)  |
|  (bit) 1,048,576 بت | (Kb) كيلوبت (Kb) | (Mb) 1 ميجابايت (Mb)  |
|  (bit) 1,073,741,824 بت | (Mb) ميجابايت (Mb) | (Gb) 1 جيجابايت (Gb)  |
|  (bit) 1,099,511,627,776 بت | (Gb) جيجابايت (Gb) | (Tb) 1 تيرابايت (Tb)  |

هناك أيضًا وحدات معلومات أخرى تُعرَّف على أنها مضاعفات البتات، والأكثر شيوعًا هو البايت (Byte)، وهو متكون من 8 بتات.

|  وحدات المعلومات  |   |   |
| --- | --- | --- |
|   | (bit) 8 bits | (Byte) 1 بايت  |
|  (bit) 8,192 بت (bit) | (Byte) 1024 بايت | (KB) 1 كيلوبايت (KB)  |
|  (bit) 8,388,608 بت (bit) | (KB) 1024 كيلوبايت (KB) | (MB) 1 ميجابايت (MB)  |
|  (bit) 8,589,934,592 بت (bit) | (MB) 1024 ميجابايت (MB) | (GB) 1 جيجا بايت (GB)  |
|  (bit) 8,796,093,022,208 بت (bit) | (GB) 1024 جيجا بايت (GB) | (TB) 1 تيرابايت (TB)  |
