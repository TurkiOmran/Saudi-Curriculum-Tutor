# التعامل مع النسب المئوية
قد يكون التعامل مع النسب المئوية (Percentages) غير واضح بعض الشيء، ولكن مع التدريب سيكون كل شيء واضحًا.

اكتب الجدول التالي ونسّقه كما هو موضح:

|  D | C | B | A  |
| --- | --- | --- | --- |
|  المملكة العربية السعودية  |   |   |   |
|  مساحة سطح الماء (كم²) | مساحة سطح اليابسة (كم²) | 2 |   |
|  2,149,960 | 2,134,912.17 | 15,047.83 | 3  |
|   |  |  | النسبة المئوية  |
|   |  |  | 5  |

## لحساب النسب المئوية:

1. Ctrl + Enter
2. Ctrl + Enter
