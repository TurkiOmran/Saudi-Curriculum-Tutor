مثال 1: موجب أو سالب أو صفر
يستخدم المقطع البرمجي جملة if ... elif ليقرأ رقمًا ويتحقق مما إذا كان الرقم موجبًا أم سالبًا أم صفرًا ثم يطبع الرسالة المقابلة.

![img-254.jpeg](img-254.jpeg)

```python
print(":x من فضلك أدخل قيمة المتغير x")
x=int(input())
```

```python
print(":x" من فضلك أدخل قيمة المتغير x)
x=int(input())
```

```python
if x&gt;0:
print("رقم موجب x")
elif x&lt;0:
print("رقم سالب x")
else:
print("يساوي صفر x")
```
