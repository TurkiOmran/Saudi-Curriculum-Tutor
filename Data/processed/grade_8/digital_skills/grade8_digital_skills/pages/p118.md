## المعاملات المنطقية في بايثون

قد تحتاج إلى دمج مقارنات متعددة في المعاملات الشرطية، في هذه الحالة تُستخدم المعاملات المنطقية، وكذلك تُستخدم لدمج شرطين أو أكثر.

من أجل فهم استخدام المعاملات المنطقية بشكل أفضل، يمكنك الرجوع إلى جدول الحقيقة.

جدول الحقيقة هو جدول يسرد جميع المدخلات الممكنة للمتغير، ويعرض مخرجاته وفقًا للمعامل المنطقي كما يظهر بالأسفل:

### ترتيب المعاملات في البرمجة

()

**

*

/

+ -

== &gt; &lt;

&lt;= &gt;= =!

## جدول الحقيقة

|  a | B | A and B | A or B | not A | not B  |
| --- | --- | --- | --- | --- | --- |
|  True | True | True | True | False | False  |
|  False | True | False | True | True | False  |
|  True | False | False | True | False | True  |
|  False | False | False | False | True | True  |
